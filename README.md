# PromptsArabic Studio

استوديو عربي لتعلّم صناعة الفيديو بالتطبيق. يضم تسع صفحات، وثمانية دروس، و24 برومبتًا، وأربعة أدلة إنتاج، وعشر أدوات تشمل محررًا مفتوح المصدر لا يتطلب حسابًا.

- [المنصة على GitHub Pages](https://kgcfod-ops.github.io/PromptsArabic-Studio/)
- [المجتمع على تيليجرام](https://t.me/PromptsArabic)

## التطوير والتشغيل

الصفحات HTML متعددة مع وحدات JavaScript أصلية وCSS مشترك. يبني Node الصفحات التسع من قوالب ومصادر بيانات موحدة. ينتج هذا الحل روابط صفحات ثابتة ويحتفظ بإعداد GitHub Pages الحالي من فرع `main` وجذر المستودع. لا تحتاج النسخة المنشورة إلى Node أو مكتبات تشغيل خارجية.

يتطلب التطوير Node 22 أو أحدث. شغّل:

```bash
npm ci
npm run build
npm run check
npm test
npx playwright install chromium
npm run test:browser
```

ينشئ اختبار المتصفح خادمًا محليًا تحت المسار `/PromptsArabic-Studio/` ويكتب النتائج واللقطات في `test-results/`. لاختبار موقع Pages المنشور شغّل `STUDIO_LIVE=https://kgcfod-ops.github.io/PromptsArabic-Studio/ npm run test:browser`. للمعاينة اليدوية شغّل `python3 -m http.server 8000` وافتح `http://localhost:8000`.

## المساهمة والنشر

- عدّل المحتوى في `assets/js/data/`، والقوالب المشتركة في `home.mjs` و`pages.mjs`. أعد بناء ملفات HTML بعد التعديل وأدرجها في الالتزام.
- حدّث وصف قيود الأداة ومصادرها وتاريخ المراجعة معًا. لا تثبت أسعارًا أو حصص أرصدة متغيرة دون مصدر. الدرس التعليمي المحوري يربط بمرجع USGS.
- اختبر على فرع تطوير قبل الدمج إلى `main`. بعد الدمج راقب مهمة `pages build and deployment` ثم افتح المسارات المباشرة على الرابط العام.
- نقطة الرجوع قبل الإصدار `backup/pre-studio-v2` عند `4c4831a`. للتراجع عن إصدار مدمج، أنشئ التزام عكس عبر فرع إصلاح ثم ادمجه. لا تستخدم إعادة كتابة تاريخ `main`.
- تُحفظ المفضلة والاختيارات والتقدّم وتفضيل الحركة داخل المتصفح تحت مفتاح `promptsarabic-studio` بالإصدار 1. تبقى علامات التحقق القديمة قابلة للعرض في قسم إنجازات الإصدار السابق.

## الأصول

خط Cairo موزّع بترخيص SIL Open Font License في `assets/fonts/OFL.txt`. الأيقونات المتناسقة والشعار المصغر مرسومة لهذا المشروع. أغلفة مشاريع الاستوديو صور توضيحية مولّدة خصيصًا للموقع وتُعرض بصيغة WebP. لا يتضمّن الموقع شعارات أدوات مستنسخة، والتسميات القصيرة على بطاقاتها نصية.
