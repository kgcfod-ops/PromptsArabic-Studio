# PromptsArabic Studio
منصة عربية تعليمية لتعلّم إنتاج الفيديو بالذكاء الاصطناعي، بمسارات تناسب الحسابات المجانية والمحدودة والمدفوعة.

> حالة المشروع: قيد التطوير. لا تنشر رابط GitHub Pages للمتابعين قبل اختبار الصفحات واعتماد المحتوى.

## هدف المنتج
يختار المتعلم نوع الفيديو وجهازه وميزانيته، ثم يتبع دروسًا تطبيقية، ويستخدم دليل الأدوات والبرومبتات الجاهزة لبناء مشروع فيديو من الفكرة حتى التصدير.

## خطة الصفحات التسع
1. `index.html`: الرئيسية ونقطة البداية.
2. `paths.html`: اختيار نوع الفيديو والميزانية والجهاز.
3. `lesson.html`: درس تطبيقي خطوة بخطوة.
4. `tools.html`: دليل الأدوات ومتطلبات الحساب.
5. `projects.html`: معرض مشاريع يمكن تطبيقها.
6. `prompts.html`: مكتبة برومبتات مع تخصيص ونسخ.
7. `compare.html`: مقارنة المجاني والمحدود والمدفوع.
8. `roadmap.html`: خريطة التعلم.
9. `about.html`: عن المنصة وحدودها.

## التقنيات
HTML + CSS + JavaScript دون باك-إند أو بيانات حسابات مستخدمين. هوية خضراء، واجهة RTL وخط Cairo، مع تصميم للجوال أولًا.

## معايير التشغيل والنشر
- عمل الروابط النسبية تحت `/PromptsArabic-Studio/` على GitHub Pages.
- عدم اعتماد استضافة API أو مفاتيح سرية داخل الموقع.
- لا تعرض أسعارًا أو أرصدة متغيرة على أنها مضمونة؛ أدرج تاريخ التحقق والروابط الرسمية.
- لا تعرض مشغلات فيديو أو تنزيلات وهمية.
- يمكن حفظ تقدم الدروس محليًا في المتصفح فقط، دون حساب مستخدم أو مزامنة بين الأجهزة.
- اختبر الشاشات الصغيرة، اتجاه العربية، لوحة المفاتيح، البحث، الفلاتر، النسخ، وإمكانية التصفح.

## النشر عند جاهزية المشروع
